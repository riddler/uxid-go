## Unreleased

The module is being rewritten as the Go port of uxid: prefixed, K-sortable
identifiers a person can read, wire-compatible with the Elixir `uxid` package.
No version of the module has been tagged yet. This change lays down the
scaffold only: the module path `github.com/riddler/uxid-go`, the package
`uxid`, a `Version` constant and the build gate. The generation, decoding and
validity checks arrive in later changes.
